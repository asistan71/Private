# Piyasa Terminali – Android
1. github.com'da yeni (private olabilir) bir depo açın, bu klasörün TÜM içeriğini (.github dahil) yükleyin.
2. Depoda Actions sekmesi -> "APK derle" -> Run workflow (yükleme yapınca kendiliğinden de başlar). ~5 dk sürer.
3. Bitince çalıştırmanın altındaki Artifacts -> piyasa-terminali-apk indirin, zip'ten app-debug.apk çıkarın.
4. Telefonda APK'ya dokunup kurun ("bilinmeyen kaynaklara izin ver" gerekebilir).
Not: www/index.html tarayıcıda da açılır (BIST/Binance istekleri tarayıcıda CORS yüzünden engellenebilir; APK'da Capacitor bunu aşar).
